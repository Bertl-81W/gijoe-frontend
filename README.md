# GI Joe Character Tracker

A React application that consumes the GI Joe API and displays military-style character dossier cards inspired by 1980's action figure file cards.

## Features

- Search GI Joe characters
- Add new characters
- Edit existing characters
- Delete characters
- Faction support
- character cards
- Military dossier inspired UI
- Responsive design (under construction)

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Fetch API

## Running the Application

Install depenencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Visit:

```text
http://localhost:5173
```
